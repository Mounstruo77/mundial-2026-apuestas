# ⚽ Mundial 2026 — Apuestas

App web de apuestas para el Mundial 2026 entre amigos. Sin registro, sin servidor, funciona directo en el navegador.

## 🚀 Ver la app

👉 **[mundial2026.github.io/mundial-2026-apuestas](https://TU_USUARIO.github.io/mundial-2026-apuestas)**

## ✨ Funciones

- 👥 **Jugadores ilimitados** — agrega todos los amigos que quieras
- ⚽ **72 partidos de grupos** — predicciones 1/X/2 con Local / Empate / Visita
- 🏆 **Eliminación completa** — 16avos → Octavos → Cuartos → Semis → Final
- 🔄 **Bracket automático** — los ganadores avanzan solos de fase en fase
- 🌐 **Resultados automáticos** — sincroniza con [openfootball/worldcup.json](https://github.com/openfootball/worldcup.json) (gratis, sin API key)
- 🕐 **Horario Chile** — todas las horas en zona `America/Santiago`
- 🔒 **Apuestas bloqueadas** al iniciar cada partido
- 💾 **Backups automáticos** — nunca pierdas tus datos
- 📊 **Tabla general** con podio 🥇🥈🥉 en tiempo real
- 🛡️ **Seguridad** — CSP, validación de datos, rate limiting

## 🛠️ Tecnología

- HTML + CSS + JavaScript puro (sin frameworks, sin dependencias)
- `localStorage` para persistencia local
- Fuentes: [Manrope](https://fonts.google.com/specimen/Manrope) + [Anton](https://fonts.google.com/specimen/Anton)
- Banderas: [flagcdn.com](https://flagcdn.com)
- Datos: [openfootball/worldcup.json](https://github.com/openfootball/worldcup.json)

## 📦 Uso

Basta con abrir `index.html` en cualquier navegador moderno.  
Para compartir con amigos, sube a GitHub Pages (ver abajo).

## 🌐 Deploy en GitHub Pages

1. Sube este repo a GitHub
2. Ve a **Settings → Pages**
3. Source: **main** branch, carpeta **/ (root)**
4. En ~1 min tendrás la URL pública
